03 / SCIENTIFIC ML Symbolic SINDy

SIR Model Symbolic ODE Discovery

Problem: Complex stochastic biological and epidemiological systems are governed by non-linear differential equations that are rarely known a priori from raw observational trajectory data.

Approach: Fitted neural networks to simulate stochastic epidemic state paths, extracted exact continuous temporal derivatives using PyTorch autograd, and applied LASSO sparse regression over a candidate polynomial library to symbolically rediscover the exact SIR ODE equations.

Methods
Neural ODEs + Autograd + LASSO
Context
GSoC 2026 Scientific Discovery

04 / APPLIED ML IIT Patna Internship

Groundwater Level Analysis & Prediction

Problem: Subsurface hydrological levels fluctuate under intricate non-linear dependencies across rainfall, geospatial terrain, seasonal drawdown, and temperature, necessitating reliable forecasting for water security.

Approach: Engineered an end-to-end data pipeline with comprehensive spatiotemporal feature engineering. Benchmarked and ensembled gradient-boosted decision trees (XGBoost, LightGBM, CatBoost), Random Forests, and Long Short-Term Memory (LSTM) recurrent networks.

Domain
Hydrological Spatiotemporal Modeling
Models

05 / FOUNDATIONS First Principles

Transformer From Scratch in PyTorch

Problem: High-level abstractions like torch.nn.Transformer hide essential tensor contractions, attention head dynamics, masking operations, and gradient flows.

Approach: Built the complete original Attention Is All You Need sequence-to-sequence architecture from pure PyTorch tensor operations: scaled dot-product multi-head self and cross attention, sinusoidal positional encodings, layer normalization, residual blocks, causal autoregressive masking, and padding masks.
