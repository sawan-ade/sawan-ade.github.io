Benchmark: 90.5%

Submanifold Sparse Convolutional Networks for High-Energy Particle Collision Discrimination

Sawan Ade · Machine Learning for Science (ML4Sci)

An empirical investigation into classifying sparse calorimeter collision events. Explores how spatial submanifold convolutions circumvent the severe memory and computational penalties of dense 2D CNNs on >95% zero-valued detector lattices. Integrates unsupervised sparse autoencoder pretraining followed by structured magnitude pruning, achieving a 90.5% classification accuracy on particle event datasets.

Research Report · 2026 Scientific ML
PyTorch Autograd + LASSO

Symbolic Discovery of Epidemiological Dynamics via Neural Autograd and Sparse Regression

Sawan Ade · Scientific Machine Learning Lab

A study on equation-free dynamical recovery from simulated stochastic epidemic trajectories. Neural networks are fitted to noisy population curves; exact continuous temporal derivatives are extracted using PyTorch autograd rather than error-prone numerical differences; and LASSO sparse regression is executed over a candidate library of nonlinear interaction terms to reconstruct the governing SIR differential equations.
